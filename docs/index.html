Windows: draw on the GPU that drives the primary display

With a low-power or high-performance preference alone, wgpu can pick a GPU that drives no monitor, for example a Ryzen iGPU on a desktop whose screens hang off an NVIDIA card. Presenting across GPUs blacked out every monitor for two minutes in PdfCraft (storytold/pdfcraft#378). The fix asks Windows which adapter drives the primary display (EnumDisplayDevices) and matches it to the wgpu adapters by PCI ids.
